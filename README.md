# Kokurikuler-Bahasa-Indonesia
Website berisi latar belakang kokurikuler, dan langkah-langkah pembuatan surat penawaran. Di website juga terdapat file dokumen surat penawaran sekaligus lampiran produk yang dapat dilihat oleh pengunjung website. Tujuannya dibuat website ini untuk melengkapi tugas terakhir kka di semeste 1.
